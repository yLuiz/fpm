# FPM - Factory Preventive Maintenance

## Sistema de Manutenção Preventiva para Chão de Fábrica

---

## O Problema

### A Realidade das Fábricas Brasileiras

Segundo dados da **ABRAMAN (Associação Brasileira de Manutenção)**, a manutenção industrial representa em média **4,5% do faturamento bruto** das empresas brasileiras. Deste valor:

- **30%** é gasto com manutenção corretiva não planejada
- **25%** das paradas não programadas poderiam ser evitadas com manutenção preventiva
- **R$ 100 bilhões/ano** são perdidos em paradas não planejadas no Brasil

### Os Equipamentos Críticos

No chão de fábrica, 5 tipos de equipamentos são responsáveis por **80% das paradas não programadas**:

| Equipamento | % de Paradas | Custo Médio por Parada |
|-------------|--------------|------------------------|
| Motores Elétricos | 28% | R$ 15.000 - R$ 50.000 |
| Compressores de Ar | 22% | R$ 20.000 - R$ 80.000 |
| Bombas Industriais | 18% | R$ 10.000 - R$ 40.000 |
| Esteiras Transportadoras | 17% | R$ 8.000 - R$ 30.000 |
| Painéis Elétricos | 15% | R$ 5.000 - R$ 25.000 |

### O Cenário Atual

A maioria das fábricas de pequeno e médio porte ainda gerencia manutenções com:

- Planilhas Excel desatualizadas
- Anotações em papel
- Memória dos técnicos
- "Apagar incêndios" quando quebra

**Resultado:** Equipamentos quebram, produção para, prejuízo acontece.

---

## A Solução: FPM

### Factory Preventive Maintenance

O **FPM** é um sistema web completo para gestão de manutenção preventiva, desenvolvido especificamente para os 5 tipos de equipamentos mais críticos do chão de fábrica.

### Proposta de Valor

> **"Transformar manutenção reativa em manutenção proativa, reduzindo paradas não programadas em até 70%"**

### Diferenciais

| Característica | Benefício |
|----------------|-----------|
| **Foco em 5 equipamentos** | Sistema especializado, não genérico |
| **Checklist por tipo** | Padronização das inspeções |
| **Agenda automática** | Nunca mais esquecer uma manutenção |
| **Dashboard visual** | Visão clara do que está vencido |
| **Simplicidade** | Curva de aprendizado de 1 dia |
| **Custo acessível** | Solução para PMEs |

## Funcionalidades

### 1. Cadastro de Equipamentos

Registre todos os equipamentos críticos com:
- Nome e identificação
- Tipo (Motor, Compressor, Bomba, Esteira, Painel)
- Localização na fábrica
- Nível de criticidade (Alta, Média, Baixa)

### 2. Agenda Automática de Manutenção

O sistema **gera automaticamente** as próximas manutenções baseado na frequência configurada:

| Tipo de Equipamento | Frequência Padrão |
|---------------------|-------------------|
| Motor Elétrico | 30 dias |
| Compressor de Ar | 15 dias |
| Bomba Industrial | 30 dias |
| Esteira Transportadora | 15 dias |
| Painel Elétrico | 60 dias |

*Frequências totalmente configuráveis pelo administrador*

### 3. Checklist Padronizado

Cada tipo de equipamento possui um checklist específico:

**Motor Elétrico:**
- Temperatura ok
- Ruído ok
- Lubrificação realizada

**Compressor de Ar:**
- Filtro verificado
- Vazamentos checados
- Pressão ok

**Bomba Industrial:**
- Vazamento checado
- Vibração ok
- Vedação ok

**Esteira Transportadora:**
- Alinhamento ok
- Tensão ok
- Motor ok

**Painel Elétrico:**
- Limpeza realizada
- Aperto de conexões
- Aquecimento checado

### 4. Dashboard de Controle

Visualize em tempo real:
- Total de equipamentos ativos
- Manutenções a vencer nos próximos 3 dias
- Manutenções vencidas (alerta vermelho)
- Manutenções realizadas no mês

### 5. Histórico Completo

Para cada equipamento:
- Todas as manutenções realizadas
- Data prevista vs data de execução
- Checklist preenchido
- Observações do técnico

## Casos de Uso

### Caso 1: Indústria Metalúrgica

**Cenário:** Fábrica com 3 compressores de ar que alimentam toda a linha de produção.

**Problema:** Compressor principal quebrou por falta de troca de filtro. Parada de 12 horas. Prejuízo de R$ 45.000.

**Com FPM:** Sistema alertaria 3 dias antes da necessidade de verificação do filtro. Manutenção preventiva de 30 minutos. Custo de R$ 200.

### Caso 2: Indústria Alimentícia

**Cenário:** Esteiras transportadoras em ambiente de alta umidade.

**Problema:** Esteira desalinhou e rasgou a lona. 6 horas de parada. R$ 18.000 de prejuízo + risco de contaminação.

**Com FPM:** Verificação quinzenal de alinhamento e tensão. Problema identificado antes da falha. Ajuste de 15 minutos.

### Caso 3: Indústria Têxtil

**Cenário:** 20 motores elétricos em máquinas de tecelagem.

**Problema:** Motor queimou por falta de lubrificação. 8 horas de parada + motor novo. R$ 25.000 de prejuízo.

**Com FPM:** Lubrificação mensal programada. Motor com vida útil estendida em 40%.

- Computador com Docker instalado
- Conexão com internet (apenas para instalação)

## Como Usar o Sistema

### Fluxo de Trabalho Diário

#### 1. Verificar o Dashboard (Início do Turno)

O supervisor ou técnico acessa o dashboard e visualiza:
- Manutenções vencidas (prioridade máxima - vermelho)
- Manutenções a vencer em 3 dias (atenção - amarelo)

#### 2. Executar Manutenções

Para cada manutenção pendente:
1. Clicar em "Registrar" na manutenção
2. Ir até o equipamento
3. Executar os itens do checklist
4. Marcar os itens realizados
5. Adicionar observações se necessário
6. Salvar

#### 3. Próxima Manutenção Automática

Ao salvar uma manutenção como concluída:
- O sistema automaticamente agenda a próxima
- Data = Data de conclusão + Frequência do tipo
- Sem intervenção manual necessária

### Fluxo de Cadastro (Administrador)

#### Cadastrar Novo Equipamento

1. Menu **Equipamentos** > **Novo Equipamento**
2. Preencher:
   - Nome (ex: "Motor Bomba Hidráulica #01")
   - Tipo (selecionar da lista)
   - Localização (ex: "Galpão B - Setor 3")
   - Criticidade (Alta/Média/Baixa)
3. Salvar

O sistema automaticamente cria a primeira manutenção agendada.

#### Ajustar Frequências

1. Menu **Configurações**
2. Alterar a frequência em dias para cada tipo
3. Salvar

*Novas frequências valem para próximas manutenções*

### Boas Práticas

1. **Verificar dashboard diariamente** - Não deixe manutenções vencerem
2. **Preencher observações** - Documente anomalias encontradas
3. **Manter cadastro atualizado** - Equipamentos novos e desativados
4. **Revisar frequências** - Ajuste conforme realidade da fábrica
